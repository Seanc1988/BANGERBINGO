# v1.13.0 Beta — Internet Phone Play

## What is implemented

- New Host **Phone Play** tab.
- Six-digit live game PIN.
- Same-Wi-Fi phone URL.
- Internet/cellular phone access using a temporary Cloudflare Quick Tunnel for beta testing.
- QR code generation from the Host screen.
- Connected-player count.
- Separate Socket.IO `/phone` namespace for guest devices.
- Public tunnel requests are blocked from opening the Host UI / main control namespace.

## Phone game modes

### Music Bingo
The host loads a playlist into the existing Bingo Card Builder and sends that song pool to the selected phone round. Guests receive randomized 5×5 Music Bingo cards and tap squares as songs play.

### Classic Bingo
Guests receive randomized 75-ball cards with a FREE center. Called numbers update live on the card while guests mark their own squares.

### Keno
Guests can select up to 20 numbers before the draw. Called numbers and hits update live during the game.

## Beta internet workflow

1. Launch BANGER BINGO.
2. Open **Phone Play**.
3. Enable guest phone play.
4. Click **Start Internet Phone Access**.
5. On first use, BANGER BINGO downloads the official `cloudflared` helper.
6. Wait for **Internet Live**.
7. Scan the QR code from a phone using cellular data or another Wi-Fi network.
8. Join with the current six-digit game code.

## Security

The Quick Tunnel exposes only the guest phone experience. BANGER BINGO rejects public-tunnel access to the Host web UI and rejects main Host Socket.IO namespace connections coming through the tunnel.

## Commercial-release direction

Cloudflare Quick Tunnels are only being used to accelerate beta testing. The public address changes whenever the tunnel is restarted and this is not the intended sale-ready infrastructure.

Before commercial launch, migrate the same phone protocol to a dedicated BANGER BINGO cloud relay/session service and branded URL such as `play.bangerbingo.com`.
